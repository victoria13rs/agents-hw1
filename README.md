# ДЗ 1 · Создание ИИ-агентов с нуля · Вариант A

Мини-трекер учебных задач, сделанный двумя способами: прямым заданием (v1) и через спецификацию в формате OpenSpec (v2). Спецификация в формате OpenSpec, без CLI.

- **Дата:** 13 ноября 2026
- **Отчет:** [REPORT.md](REPORT.md)

## Как запустить

Скачайте нужный HTML-файл и откройте его двойным щелчком в браузере. Сервер, установка и интернет не нужны.

| Файл | Что это |
|---|---|
| `v1/tracker-v1.html` | Чат 1, прямое задание, исходная версия без правок |
| `v1/tracker-v1-fixed.html` | Чат 1 после одного исправления (границы часов) |
| `v2/tracker-v2.html` | Чат 2, реализация по спецификации, без правок |

## Что в репозитории

- `prompts.txt` — все промпты в порядке отправки, включая исправление.
- `spec/` — четыре документа спецификации из чата 2: `proposal.md`, `specs/tracker/spec.md`, `design.md`, `tasks.md`.
- `chat-logs/` — полные ответы модели на каждое сообщение.
- `checks/` — скрипты проверок T1–T5 и их результаты в JSON.
- `screenshots/` — скриншоты обеих версий: обычная ширина, 390 px, ошибка ввода.

## Как повторить проверки

Проверки T1–T5 автоматизированы на Python + Playwright в Google Chrome:

```
pip install playwright
python checks/run_checks.py v1 v1/tracker-v1.html screenshots
python checks/run_checks.py v1 v1/tracker-v1-fixed.html screenshots
python checks/run_checks.py v2 v2/tracker-v2.html screenshots
python checks/extra_checks.py
```

Каждая проверка запускается в новом контексте браузера с чистым localStorage, то есть на исходном примере.

## Ограничения

- Это вариант A: OpenSpec CLI и валидатор не запускались, спецификация проверена чтением.
- Сохранение в localStorage при открытии через `file://` зависит от браузера. В Chrome 157 данные пережили перезагрузку; в других браузерах и приватном режиме может быть иначе.
- Ключей, `.env` и личных данных в репозитории нет.
